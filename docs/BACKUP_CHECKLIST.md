## 3. 取得するもの

- [ ] Database: roles、schema、dataを取得した
- [ ] Auth: Authユーザーを含む完全復旧方式か確認した（通常のCLI dumpだけで含まれると仮定しない）
- [ ] DB外の設定を別の暗号化された運用台帳へ記録した
  - [ ] Auth provider、SMTP、redirect URL
  - [ ] Realtime publication
  - [ ] Edge Function secrets
  - [ ] API/JWT keys（値は安全な秘密管理へ、台帳には保管場所だけ）
- [ ] Dashboardで確認した全Storage bucketの一覧と、public/private、容量上限、MIME設定を記録した
- [ ] 全Storage bucketのファイル本体を、bucketごとに取得した
- [ ] DBのStorage metadataだけでファイル本体を代用していない
