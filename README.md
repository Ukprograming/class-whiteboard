# Class Whiteboard

教員と生徒がリアルタイムにホワイトボード、画面確認、チャット、フォーム、ノート画像を共有する
教室向けWebアプリです。

## カメラ・音声・背景

動画・音声ファイルの挿入上限は **1ファイル45MB（45,000,000バイト）** です。
動画の時間には挿入制限を設けていないので、10分の動画も容量内なら挿入できます。
上限を超えるファイルは挿入前に案内し、ボードや元ファイルを変更しません。
事前に圧縮するか、動画の場合は学校で利用できるYouTube動画のURLを貼り付けてください。
自動圧縮や、外部サービスへの自動アップロードは行いません。

10分動画の圧縮例は映像500kbps＋音声64kbpsで約42MB（目安）です。
出力後に実際の容量と文字・動きの見やすさを確認してください。
このファイル挿入の上限と、下記のカメラ録画の時間制限は別です。

6MiBを超えるボード資産は、進捗を表示して再開可能な方式で送信します。
一時的な通信エラー時は自動で再試行し、送信済みの位置から続けます。
再試行しても失敗した場合は保存エラーを表示します。画面を閉じずに接続を確認して再保存してください。
同じ保存先の途中アップロードは、ブラウザに再開情報が残っていれば再利用します。
新規保存のやり直し・保存先の変更・ブラウザの保存情報削除時は最初から送信することがあります。
タブを閉じた後に動画本体まで復元して送信を続ける仕組みではありません。

大容量送信には固定バージョン `tus-js-client@4.3.1` を `esm.sh` から読み込みます。
通常のSupabase URLでは `<project>.storage.supabase.co` へ送信します。
学校のネットワークでは、既存の接続先に加えてこれらの接続が許可されていることを確認してください。
DB・RLSの変更は不要です。無料枠の総保存容量・転送量の上限は引き続き適用されます。

- カメラを開くと「写真／動画」を切り替えられます。写真は撮影後、動画は
  「録画を開始」→「録画を停止」の後にプレビューを確認し、「ホワイトボードに挿入」を押します。
  動画は最大2分・約40MBです。マイクの使用が許可されない場合は音声なしで録画し、画面に表示します。
  録画中はモードとカメラの変更を停止し、閉じると録画を破棄してカメラ・マイクを終了します。
- 「画像・動画・音声を挿入」から音声ファイルも選択できます。MP3・WAVなど、利用中のブラウザで
  再生できる形式が対象です。音声カードの再生ボタンでプレーヤーを開き、「編集に戻る」で移動・
  サイズ変更に戻れます。削除・元に戻す・保存・読込・クラスへの配布にも対応します。
- 右下の背景スイッチで「グリッド／横罫線／白紙」を選択できます。選択はページごとに保存されます。
  横罫線の間隔はグリッドと同じで、ズームに追従します。

カメラはHTTPSまたはlocalhostで利用してください。iPhone・iPadは既存のカメラ起動制限を継続しているため、
端末のカメラで撮影してから「画像・動画・音声を挿入」で選択してください。
動画・音声の再生操作は端末ごとに行います。PNG書き出しには再生用カードの見た目が含まれます。

導入時はフロントエンドと `supabase/functions/copy-board-to-class` を更新してください。
この追加機能のためのDBマイグレーションは不要です。Storageバケットに独自のMIME制限を設定している場合は、
使用する音声・動画形式を許可してください。

検証：`npm.cmd test` は既存チェックと音声・動画資産の保存／復元／配布のローカル検証を実行します。
容量境界、再開情報の送信先、認証ヘッダー更新、再試行対象、進捗通知も検証します。
`node scripts/verify-tus-protocol.cjs` は実際のtusクライアントとローカルの送信先で中断・再開を検証します。
実行時は `TUS_MODULE` にインストール済みの `tus-js-client@4.3.1` のパスを設定してください。
`node scripts/verify-media-browser.cjs` はPlaywrightとEdgeを使った模擬カメラでのUI検証です。
必要に応じて `PLAYWRIGHT_MODULE` にPlaywrightのパス、`PLAYWRIGHT_CHANNEL` にブラウザのchannelを設定します。
公開環境のカメラ・マイク権限、実機の撮影品質、教師と生徒の別端末間の保存・配布は別途確認してください。

## 授業フォーム

教師画面の上部にあるフォームボタンから、自由記述・単一選択・複数選択の問題を
作成して保存できます。クラスへ配信すると、生徒画面に回答ダイアログが表示され、
教師画面では回答人数、選択問題の棒グラフ、自由記述の一覧をリアルタイムで確認できます。
受付を終了した結果は実施履歴から問題ごとに再表示できます。

利用前に、既存のSupabaseマイグレーション適用手順で
`supabase/migrations/20260830062951_add_class_forms.sql` を対象環境へ適用してください。

## ローカル確認

```powershell
npm.cmd ci
npm.cmd run check
npm.cmd start
```

`http://localhost:3000/` を開きます。

秘密鍵、DBパスワード、教師招待コード、実在する生徒の個人情報はリポジトリへ
コミットしないでください。
